API를 직접 활용하려면?

OpenShelf는 검색·탐색을 돕습니다. 실제 API 요청은 제공기관별 인증키, 이용 조건, 승인 여부 및 CORS 정책을 확인해야 합니다. 인증키를 이 사이트에 입력하거나 저장하지 않습니다.
