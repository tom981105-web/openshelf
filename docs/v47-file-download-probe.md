# OpenShelf V47 — 실제 CSV·엑셀 접근 시험

V46의 86,411건 목록에서 100건을 조사하고, 공식 상세페이지의 HTML에서 실제로 발견된 **직접 CSV / XLS / XLSX URL 후보만** 대상으로 최대 20개를 시험합니다.

- HTTPS 공공데이터포털 호스트만 허용합니다.
- 파일별 최대 2 MiB를 메모리에서 읽어 응답 본문 및 형식을 점검합니다. 저장소에 원본을 커밋하지 않습니다.
- 로그인 HTML, 오류 페이지, 리다이렉션, 과대 파일, 미확인 형식은 성공으로 표시하지 않습니다.
- 파일 URL이 V46 조사에서 발견되지 않으면 **0건 검사**로 보고합니다. 이는 86,411개 가운데 다운로드 가능 파일이 0개라는 의미가 아닙니다.
- JSON 보고서는 GitHub Actions 아티팩트로 저장합니다. 이 수치만으로 전체 원본 용량, 다운로드 가능률, 재배포 가능 여부를 추정하면 안 됩니다.

실행 경로: GitHub Actions → **V47 limited CSV and Excel file probe** → **Run workflow**. CI에서는 인터넷 원본을 다운로드하지 않고 모의 응답 테스트만 합니다.

후속 단계에는 상세페이지의 실제 다운로드 버튼 및 API 경로를 규정과 이용 조건에 맞게 확인하고, 수집량을 늘리기 전에 원본 파일을 별도 보관할지 검토해야 합니다.
