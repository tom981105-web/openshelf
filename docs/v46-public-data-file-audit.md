# V46 — 파일데이터 원본 접근 실태 조사

**현재 86,411건은 원본 파일이 아니라 공공데이터포털 메타데이터 목록입니다.**

이 패치는 목록에서 균일 간격으로 **100건**을 선정해 각 공식 상세페이지가 열리는지 조사합니다. 원본 파일은 내려받지 않으며, HTML에서 발견되는 다운로드 링크는 **검증 전 후보**로만 표시합니다. 상세페이지의 HTTP 200 응답은 파일 다운로드 성공이 아닙니다. 따라서 원본 크기를 0 또는 HTML의 Content-Length로 추정하지 않습니다.

실행: GitHub Actions → **V46 public file data availability survey** → Run workflow → 표본 수 선택.

작업 완료 후 **public-data-v46-audit** 아티팩트에서 JSON 세부 결과와 Markdown 보고서를 확인하세요. 인증·포털 차단·동적 버튼·외부 링크는 별도 후속 확인이 필요할 수 있습니다.

CI에서는 실제 100건 온라인 요청을 수행하지 않고 **표본 선정/응답 분류의 오프라인 테스트**만 실행합니다. 별도 워크플로를 수동 실행해야 실제 HTTP 조사가 수행됩니다. 원본 저장용량, 다운로드 성공률, 재배포 가능 여부는 아직 확정할 수 없습니다.

후속 단계: 실제 다운로드 URL이 확인된 파일에 한해 작은 범위 요청으로 크기·유형·이용조건을 검증하고, CSV/XLSX 내용 색인의 규모를 산정합니다. 기존 메타데이터, OpenShelf 웹사이트 및 수집 자동화는 변경하지 않습니다.
