# V40: 각 PC별 개인 Gemini API 키
- 통합 검색의 **개인 Gemini API 키 설정**에서 자신의 API 키를 입력하고 12자 이상의 잠금 비밀번호를 설정합니다.
- 키는 현재 브라우저의 localStorage에 PBKDF2(SHA-256, 310,000회)로 유도한 AES-GCM 키로 암호화하여 저장합니다. 비밀번호는 저장하지 않습니다. **키를 사용하려면 매번 브라우저에서 비밀번호로 잠금을 해제해야 합니다.** 잠금 해제된 키는 현재 탭 메모리에만 남으며 새로고침 시 다시 잠가집니다.
- 집 PC의 브라우저 저장소와 회사 PC 저장소는 분리됩니다. 같은 PC의 다른 브라우저/프로필도 별개입니다. 브라우저 동기화·확장 프로그램·기기 침해까지 막는 절대적 보안 수단은 아닙니다. 공동사용 PC에는 저장하지 마세요.
- **이 PC 키 삭제**로 암호화된 저장값을 지울 수 있습니다. 잠금 비밀번호 분실 시 복구할 수 없으며 삭제 후 재등록해야 합니다.
- Worker는 요청의 `x-openshelf-key` 개인 키만 Gemini에 전달하며 공용 `GEMINI_API_KEY` 설정을 사용하지 않습니다. Gemini 호출 시에는 키가 브라우저에서 Worker로 전송되므로 HTTPS와 Worker 운영자 신뢰가 필요합니다. 서버 로깅·오류 모니터링에 요청 헤더가 기록되지 않게 설정하세요.
- **실제 활성화 전** Cloudflare Worker에 변경된 `worker/ai-smart-search.mjs`를 재배포하고, 기존 공용 키 Secret을 제거하고, `AI_LIMITER`를 설정하고, `ai-search-config.js`에 HTTPS 엔드포인트를 지정해야 합니다. 옛 Worker 배포본은 GitHub 코드 변경만으로 수정되지 않습니다.
- API 키를 직접 웹페이지 JS 파일이나 GitHub Secrets로 복사하지 마세요. Google AI Studio에서 만든 개인 Gemini 키만 설정창에 입력합니다. 브라우저에 키를 보관한다는 사실 자체가 위험을 완전히 제거하지는 못합니다.
